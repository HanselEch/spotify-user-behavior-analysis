# Spotify User Behavior Analysis

This project analyzes a simulated dataset of 50,000 Spotify users and uses machine learning to predict whether a user converted to a subscription after interacting with an advertisement.

## What the Project Includes

- Data cleaning and exploratory analysis
- Visualizations of user behavior
- Decision Tree and Random Forest models
- Model evaluation using accuracy, precision, recall, and confusion matrices

Both models reached about 91% accuracy but struggled to identify converted users because the dataset was highly imbalanced.

## Technologies

Python, pandas, NumPy, Matplotlib, Seaborn, scikit-learn, pandasql, and Jupyter Notebook.

## Files

- `spotify_user_behavior_analysis.ipynb` — Full analysis and machine learning workflow
- `spotify_user_behavior_realistic_50000_rows.csv` — Simulated dataset
